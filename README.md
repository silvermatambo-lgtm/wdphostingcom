# WDP Hosting — Independent Website

React/Vite website with company-owned source in GitHub and automated Vercel deployment.

**Demo stage:** This Git-managed first preview uses the original WDP Hosting React website source, modernizes its wording and branding, removes proprietary website-builder dependencies, and replaces missing binary logo paths with self-hosted SVG. It is **not yet a full import** of the separately uploaded TanStack Start archive. Its Supabase-backed checkout, live domain availability, administration, and other TanStack routes are not available in this Vite preview. Do not start Google Ads or take online payments on this preview until those workflows have been validated.

## Development

`npm install && npm run dev`

## Deployment

Vercel builds main automatically. Framework Vite; output dist. No Lovable dependency.

## Ordering

Package CTAs initiate a WhatsApp enquiry; the domain form is not a registrar availability check. Confirm rates and registrations manually before issuing invoices.
